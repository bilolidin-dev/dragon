# Dragon Cursor Effect

Небольшая интерактивная веб-страница с анимированным SVG-драконом. Дракон плавно движется за указателем мыши или касанием.

## Запуск

Откройте `index.html` в современном браузере. Сборка, установка зависимостей и дополнительные инструменты не нужны.

## Управление

Перемещайте указатель по странице, чтобы направлять дракона. На сенсорном устройстве проведите пальцем по экрану.

## Структура проекта

- `index.html` — SVG-графика дракона и разметка страницы.
- `style.css` — оформление и размеры сцены.
- `script.js` — анимация и реакция на указатель.
